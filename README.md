# To-Do List Application

A modern to-do list application with local storage functionality, built with HTML, CSS, and JavaScript.

## Features

- ✅ Add, edit, and delete tasks
- 💾 Automatic local storage persistence
- ✨ Clean and intuitive user interface
- 🎯 Mark tasks as complete/incomplete
- 🔍 Real-time task management
- 📱 Responsive design

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Start adding your tasks!

## Usage

- **Add Task**: Type in the input field and press Enter or click the Add button
- **Complete Task**: Click the checkbox next to a task to mark it complete
- **Edit Task**: Click the edit icon to modify a task
- **Delete Task**: Click the delete icon to remove a task
- **Clear All**: Remove all completed tasks

## Technical Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- LocalStorage API
